# Security

Tallimo is finished and no longer maintained.

- There are no supported versions.
- No security fixes will be made, and reports are not monitored.
- Use it at your own risk. It is provided "as is", without warranty, under the Apache-2.0 licence (see [LICENSE](LICENSE)).

If you run it, keep it on 127.0.0.1 (its default bind) and use sample data only. Never commit real data, tokens, or a `.env` file to a fork.
